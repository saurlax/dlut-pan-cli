## dlut-pan space naosi

Show the NAOSI group and root IDs.

### Synopsis

Print known NAOSI identifiers. This does not check or modify your membership.

```
dlut-pan space naosi [flags]
```

### Examples

```
  dlut-pan space naosi --json
```
